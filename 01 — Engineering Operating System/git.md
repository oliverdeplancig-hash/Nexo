# Git

- Branch principal: `main`. Trabalho em branches curtas: `feat/…`, `fix/…`, `docs/…`.
- Mensagens de commit em português, no imperativo: "Adiciona filtro por setor na busca".
- Commit e push somente quando solicitado pelo responsável pelo projeto.
- Nunca versionar `.env`, bancos, arquivos de `armazenamento/` ou documentos reais.
