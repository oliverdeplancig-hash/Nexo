## Brand & Style

The design system projects authority, cryptographic precision, and institutional dependability for enterprise AI integration. It is designed for knowledge workers, legal analysts, corporate executives, and compliance officers who require unquestionable source attribution, deterministic response tracking, and zero visual friction.

The style fuses **Corporate Modernism** with **Tonal Structuralism**:
- Deep, command-level architectural framing via an authoritative midnight navy navigation spine.
- Clinical, paper-pure working surfaces that focus attention on structured data, synthesized prose, and source verification.
- Purposeful visual feedback: zero ornamental clutter, strict visual hierarchy, and an unwavering commitment to WCAG AAA contrast compliance across critical reading and decision-making surfaces.

## Colors

The system uses an asymmetric structural light canvas paired with an anchor-grade dark command sidebar.

### Primary & Action
- **Primary Interactive (`#2563EB`)**: Focus rings, primary buttons, dynamic selection states, active query stems.
- **Primary Hover/Pressed (`#1D4ED8`)**: Elevated primary interaction states.
- **Primary Surface Tint (`#EFF6FF`)**: Contextual link containers, active message highlights.

### Anchor & Structural Surfaces
- **Sidebar Canvas (`#0A1128`)**: Deep obsidian base for institutional global navigation.
- **Sidebar Elevated Panel (`#0F172A`)**: Workspaces, context switchers, drawer backgrounds.
- **Sidebar Card/Hover (`#1E293B`)**: Interactive conversation threads, session tabs.
- **Sidebar Text/Icon Active (`#F8FAFC`)**: Selected thread title, active institutional modules.
- **Sidebar Text Muted (`#94A3B8`)**: Historical queries, organizational metadata.

### Working Canvas & Content Area
- **App Canvas (`#F8FAFC`)**: Document and workspace root background.
- **Work Surface (`#FFFFFF`)**: Chat streams, response cards, data inspector drawers, citation panels.
- **Surface Stroke Default (`#E2E8F0`)**: Crisp 1px partition line for cards, panels, and toolbars.
- **Surface Stroke Subtle (`#F1F5F9`)**: Inner structural separators, table borders.

### Verification & Trust Badges
- **Emerald Trust Tier (`#059669`, surface `#ECFDF5`, border `#A7F3D0`)**: Verified corporate data repository, 100% cited grounding, regulatory compliance match.
- **Cyan Retrieval Tier (`#0891B2`, surface `#ECFEFF`, border `#A5F3FC`)**: Semantic search vector matches, enterprise index sources, real-time connectors.
- **Amber Caution Tier (`#D97706`, surface `#FFFBEB`, border `#FDE68A`)**: Mixed synthesis, external context warning, unverified draft.

### Typography & Neutrals
- **Text Headings / Emphasized (`#0F172A`)**: WCAG AAA standard (>12:1 against light canvas).
- **Text Body (`#1E293B`)**: Main synthesized prose, structured metadata.
- **Text Secondary / Muted (`#475569`)**: Supporting labels, timestamps, token counters.

## Typography

The typography is built entirely on `Inter` with tabular figures enabled (`font-variant-numeric: tabular-nums`) for structured enterprise data, citation tallies, timestamps, and confidence percentages. `JetBrains Mono` is reserved exclusively for citation IDs, document checksums, API keys, and inline code representations.

### Hierarchy & Usage Rules
- **Line Length**: Paragraphs of generated AI responses are constrained to `max-width: 68ch` to maintain optical tracking stability.
- **Line Height Precision**: Body text uses loose, comfortable vertical rhythms (`1.6x`) to prevent cognitive exhaustion during long-form document reading.
- **Citations & Document Anchors**: Inline citation references use `label-sm` with a strict baseline alignment to avoid shifting paragraph leading.

## Layout & Spacing

The workspace uses a persistent split-pane operational model:

### Workspace Architecture
- **Sidebar Navigation**: Fixed `280px` desktop navigation spine (`320px` when expanded with source hierarchy tree). Collapsible to an `80px` rail on medium screens (`< 1024px`) and an absolute off-canvas sheet on mobile (`< 768px`).
- **Main Interaction Canvas**: Fluid conversational feed centered at `max-width: 896px` (56rem) to prevent overly wide, unreadable chat lines.
- **Inspector / Source Panel**: Collapsible secondary right rail (`380px`) used for side-by-side document verification, PDF page rendering, and grounding extraction details.

### Breakpoint Adaptation
- **Desktop (>= 1280px)**: Three-pane layout (Sidebar + Central Query Stream + Citation Inspector).
- **Tablet (768px - 1279px)**: Two-pane layout with the Citation Inspector shifting to an overlay slide-out sheet.
- **Mobile (< 768px)**: Single-pane stack with bottom-pinned prompt input and top-level drawer controls.

## Elevation & Depth

Visual hierarchy relies on crisp borders and functional structural layering rather than dramatic skeuomorphic shadows.

### Elevation Levels
- **Level 0 (Base Canvas)**: `#F8FAFC`. Zero elevation, non-interactive foundation.
- **Level 1 (Surface Cards & Message Nodes)**: `#FFFFFF` surrounded by a continuous `1px solid #E2E8F0` border. Ambient shadow: `0 1px 2px 0 rgba(15, 23, 42, 0.04)`.
- **Level 2 (Interactive Flyouts & Floating Bar)**: `#FFFFFF` with `1px solid #CBD5E1` border and structured lift shadow: `0 4px 6px -1px rgba(15, 23, 42, 0.08), 0 2px 4px -2px rgba(15, 23, 42, 0.04)`. Used for the fixed-bottom prompt bar, citation hovercards, and dropdown menus.
- **Level 3 (Modal Dialogs & Context Inspectors)**: `#FFFFFF` with `1px solid #94A3B8` border and command shadow: `0 20px 25px -5px rgba(15, 23, 42, 0.12), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.
- **Focus Depth Protocol**: All focused interactive controls gain a dual-ring elevation indicator: `0 0 0 2px #FFFFFF, 0 0 0 4px #2563EB`.

## Shapes

The design system maintains a calibrated **Soft (`roundedness: 1`)** architecture. This conveys institutional rigor and engineering precision without the severe harshness of 0px razor edges or the playful informality of fully rounded bubbles.

- **Base Radius (0.25rem / 4px)**: Citations, source index badges, inline code tokens, tooltips, checkboxes.
- **Component Radius (0.5rem / 8px)**: Form fields, action buttons, conversation cards, dropdown lists, message bubbles.
- **Panel Radius (0.75rem / 12px)**: Main search bar, inspector panels, modal views.
- **Pill Exceptions**: Confidence percentage pills and system availability status indicators use full rounded encapsulation (`rounded-full`) to clearly differentiate metadata markers from interactive rectangular controls.

## Components

### Buttons
- **Primary**: Background `#2563EB`, text `#FFFFFF`, border `1px solid #1D4ED8`, height `40px` (desktop), padding `0 16px`, font `label-lg`. Focus ring `2px` white inner, `2px` `#2563EB` outer. Hover: `#1D4ED8`. Active: `#1E40AF`.
- **Secondary (Institutional Outline)**: Background `#FFFFFF`, text `#0F172A`, border `1px solid #CBD5E1`. Hover: `#F8FAFC` and border `#94A3B8`.
- **Ghost / Action Icon**: Background transparent, icon `#475569`. Hover: Background `#F1F5F9`, text `#0F172A`.

### Input & Query Composer
- **Bottom Pinned Search Container**: Background `#FFFFFF`, border `1px solid #CBD5E1`, shadow Level 2, radius `12px`. Inner textarea auto-expands from `44px` to `200px`. Contains model selector, context tag pill, and voice/submit action cluster. Focused border shifts to `#2563EB` with an accessible box-shadow ring.

### Citations & Source Footnotes
- **Inline Citation Badge**: Displayed as `[1]`, `[Doc.A]`. Background `#EFF6FF`, text `#1D4ED8`, border `1px solid #BFDBFE`, radius `4px`, padding `1px 6px`, font `code-inline` (11px).
- **Interactive Citation State**: Hovering reveals an elevation Level 2 card showing the document title, exact extracted paragraph, and source match confidence score.
- **Click Action**: Opens the Citation Inspector drawer pinned to the exact highlighted sentence in the referenced PDF/document view.

### Reliability & Trust Badges
- **Verified Source Badge**: Background `#ECFDF5`, text `#065F46`, border `1px solid #A7F3D0`, font `label-sm`, uppercase, letter-spacing `0.04em`. Contains a solid check icon.
- **Enterprise Semantic Badge**: Background `#ECFEFF`, text `#0E7490`, border `1px solid #A5F3FC`. Indicates internal vector DB origin.
- **Low Confidence Warning**: Background `#FFFBEB`, text `#92400E`, border `1px solid #FDE68A`. Accompanies any response with <80% grounding support.

### Assistant vs User Message Cards
- **User Prompt**: Self-contained right-aligned or full-width container on `#F1F5F9`, border `1px solid #E2E8F0`, header with user badge and timestamp.
- **Assistant Response**: Full-width container on `#FFFFFF`, border `1px solid #E2E8F0`. Header features the institutional emblem, model version badge, generation latency, and trust rating. Footer includes copy, regenerate, export to DOCX/PDF, and feedback actions.

### Checkboxes, Radios, and Toggles
- **Checkbox/Radio**: 18px box/circle, `1.5px` border `#64748B`. Checked state: `#2563EB` with white checkmark. Focus ring compliant with WCAG AAA standards.
